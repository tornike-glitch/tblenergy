# Build scripts

The HTML pages in the repository root are generated by `build.py`.
Edit the text in these scripts (not in the generated .html files) and run:

    python3 _build/build.py

- `build.py` – page layout, header, footer, home, testing, medical, contact pages
- `services_part.py` – service list (home board + services page)
- `projects_part.py` – project galleries
- `process_part.py` – "how we work" animation
- `visuals.py` – service card illustrations

After editing assets/style.css run `python3 _build/make_light.py` to regenerate the light theme (assets/light.css).
